    <p className="text-base text-gray-600 dark:text-gray-400">Get your subscription platform running in four simple steps</p>
  </div>

  <Steps>
    <Step title="Clone and install dependencies">
      Clone the repository and install all required packages:
      
      ```bash
      git clone https://github.com/dodopayments/dodo-supabase-subscription-starter.git
      cd dodo-supabase-subscription-starter
      npm install
      ```
    </Step>
    
    <Step title="Set up your services">
      Create accounts and configure your environment:
      
      - Create a [Supabase project](https://app.supabase.com) for authentication and database
      - Create a [Dodo Payments account](https://dashboard.dodopayments.com) for subscription management
      - Set up [Google OAuth](https://console.cloud.google.com) for user authentication
      
      Copy your API keys to `.env.local`:
      
      ```bash
      NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
      NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
      DATABASE_URL=your-database-url
      DODO_PAYMENTS_API_KEY=your-dodo-api-key
      DODO_WEBHOOK_SECRET=your-webhook-secret
      ```
    </Step>
    
    <Step title="Initialize the database">
      Push the database schema to your Supabase project:
      
      ```bash
      npm run db:push
      ```
      
      This creates three tables: `users`, `subscriptions`, and `payments`.
    </Step>
    
    <Step title="Start developing">
      Launch the development server:
      
      ```bash
      npm run dev
      ```
      
      Open [http://localhost:3000](http://localhost:3000) and start building your SaaS application.
    </Step>
  </Steps>
</div>
